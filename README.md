# La Habra Christian Church website

Live at https://lahabrachristian.github.io/

To edit text, photos and events from a phone: go to https://app.pagescms.org, sign in with GitHub, and open this repository.

Content lives in `_data/*.yml` (page text, church info, pastors, gallery) and `_events/` (one file per event). Layout and design live in the `.html` files, `_layouts/` and `styles.css`.
